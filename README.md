📊 Amazon Sales Data Analysis

This project analyzes Amazon sales transaction data to uncover insights, clean messy datasets, and build interactive dashboards for decision-making.

🔎 Key Highlights

Data Cleaning & Preprocessing

Handled missing values, duplicates, and inconsistent formats

Standardized categorical values (e.g., product categories, regions)

Converted and normalized date/time features for trend analysis

Exploratory Data Analysis (EDA)

Identified top-selling categories, regions, and products

Analyzed seasonal patterns and monthly/quarterly sales trends

Performed customer segmentation based on order behavior

Dashboard & Visualization

Built interactive dashboards (Power BI / Tableau / Plotly)

Visualized KPIs such as revenue, profit margins, and regional sales distribution

Highlighted trends, anomalies, and actionable insights

Business Insights

Optimized product mix recommendations

Found sales peaks aligned with seasonal events

Provided insights for inventory and supply chain decisions
